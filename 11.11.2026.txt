1.Screen Space (Overlay / Camera).Интерфейс всегда отображается поверх экрана устройства. Он привязан к 2D-плоскости камеры и следует за взглядом пользователя. Элементы не зависят от глубины 3D-сцены.
World Space.Canvas становится полноценным 3D-объектом в сцене. Он имеет собственные координаты, вращение и масштаб. Его можно расположить на поверхности 3D-объекта (например, на панели управления станком), он уменьшается при отдалении камеры и может перекрываться другими 3D-моделями.
2.Размер определяет, сколько пикселей будет занимать текст на экране при заданном расстоянии от камеры (особенно критично для World Space). Если панель слишком маленькая или камера далеко, текст начнет размываться.
Положение, влияет на угол обзора и контрастность. Текст на панели, расположенной под острым углом к камере или на сливающемся с текстом фоне, нечитаем. Панель должна быть перпендикулярна взгляду пользователя (или использовать скрипт Billboard для поворота за камерой) и иметь контрастную подложку (фон).

4.Для этого нужно получить ссылку на компонент UI и присвоить значения из вашего класса данных в свойство text, предварительно конвертировав их в строку.
using UnityEngine;
using TMPro;
public class TelemetryDisplay : MonoBehaviour
{
    public TextMeshProUGUI coordinatesText; 
    public void UpdateTelemetryUI(MachineState state) 
    {
        if (state != null && coordinatesText != null)
        {
            coordinatesText.text = $"X: {state.x}\nY: {state.y}\nZ: {state.z}"; 
        }
    }
}
