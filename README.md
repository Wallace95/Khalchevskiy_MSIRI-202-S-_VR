# VR-симулятор сверлильного станка и производственного участка (`Khalchevskiy_MSIRI-202-S-_VR`)

Учебный VR-проект на базе **Unity** и **SteamVR**, моделирующий работу ручного сверлильного (фрезерного) станка и взаимодействие оператора с производственным окружением в виртуальной реальности.

---

## Основной функционал

* **Управление узлами станка:**
  * Перемещение рабочего стола (`Cube.002`) и привода рабочей части (опускание и подъем фрезы/сверла) через панель управления.
  * Ручное управление штурвалом (рукояткой) станка в VR: вращение против часовой стрелки опускает фрезу, по часовой — поднимает.
* **Генерация и физика заготовок:**
  * Спавн физических заготовок по нажатию UI-кнопки.
  * Поддержка компонентов `Interactable` и `Throwable` (SteamVR) — заготовки можно брать контроллерами, размещать на станине и бросать.
* **Интерактивный интерфейс (World Space UI):**
  * Панель управления с кнопками запуска, остановки и спавна деталей.
  * Вывод текущего статуса работы станка и параметров состояния (`MachineState`) в реальном времени на текстовые экраны (`TextMeshPro` / `UI Text`).
* **Проработанное физическое окружение цеха:**
  * Настроенные коллайдеры и физика (`Rigidbody`, `MeshCollider`, `BoxCollider`) для объектов промышленной сцены: паллет (`PaletteWooden`), бочек (`Barrel`), защитных барьеров (`Barrier`), сигнальных конусов (`Cone`) и ограждающих конструкций.

---

## Технологический стек

* **Движок:** Unity (3D)
* **Язык программирования:** C#
* **VR-фреймворк:** SteamVR Plugin / OpenVR
* **Интерфейс:** Unity UI (`Canvas` в режиме World Space), TextMeshPro
